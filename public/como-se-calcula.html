Como se calcula o Índice de Condição

É um indicador editorial, não científico. Junta meia dúzia de sinais públicos numa só leitura para dar uma ideia do momento. Não mede o sofrimento de ninguém e não prevê nada.

Passo a passo

  1. Cada sinal tem um valor "calmo" e um valor "alarme", escolhidos por nós. O valor de hoje é convertido numa escala de 0 (calmo ou melhor) a 100 (alarme ou pior).
  2. O índice é a média ponderada dessas escalas. Os pesos estão na tabela.
  3. Se um sinal não tem dados recentes, fica de fora e os pesos dos restantes são reescalados. A tabela mostra o peso efetivo de cada um.
  4. O estado sai do índice: ESTÁVEL abaixo de 40, CUIDADO a partir daí, PERIGO a partir de 65.
  5. Para a linha não saltar entre estados a cada atualização, há uma margem de 3 pontos: para subir de estado o índice tem de passar o limiar mais essa margem; para descer, tem de ficar abaixo do limiar menos a margem.
  6. O ritmo do monitor (batimentos por minuto) é só uma tradução visual do índice.
