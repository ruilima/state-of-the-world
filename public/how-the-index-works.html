How the index is calculated

The Condition Index is an editorial indicator, not a scientific one. It folds a handful of public signals into one reading to give a sense of the moment. It does not measure anyone's suffering and it does not predict anything.

Step by step

  1. Each signal has a "calm" value and an "alarm" value, chosen by us. Today's value is placed on a scale from 0 (calm or better) to 100 (alarm or worse).
  2. The index is the weighted average of those scales. The weights are in the table.
  3. If a signal has no recent data, it is left out and the other weights are rescaled. The table shows each signal's effective weight.
  4. The state comes from the index: STABLE below 40, CAUTION from there, DANGER from 65.
  5. So the monitor does not flip between states on every update, there is a margin of 3 points: to move up a state the index must pass the threshold plus the margin; to move down it must drop below the threshold minus the margin.
  6. The monitor's pulse (beats per minute) is only a visual translation of the index.

Where to change it
